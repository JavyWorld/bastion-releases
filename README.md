# BASTIÓN: Colonia Infinita — versiones

Este repositorio solo guarda los APK publicados del juego (no el código fuente).
El juego consulta la última versión en el servidor y, si hay una más nueva, muestra
el botón **Actualizar**, que descarga el APK de aquí, comprueba su huella SHA-256 y lo instala.

- `apk/Bastion-<versión>-<código>.apk` — cada versión publicada.

Instalación manual (solo la primera vez): abre en el teléfono el enlace del APK más reciente
de la carpeta `apk/`, descárgalo e instálalo. A partir de ahí, las actualizaciones llegan desde el juego.
